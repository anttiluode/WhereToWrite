Subject minus unrelated-word accuracy **-3.0 percentage points**. The point estimate goes *against* the proposed privilege for the subject token.

The original tool reported the normal interval **[-7.21, +1.21] percentage points**, but that calculation incorrectly treats all 400 evaluations as independent. **Do not use this interval for inferential claims** without the duplicate-case correction below.

## Sampling audit

The historical benchmark deterministically cycles through **8 names** and **3 question templates**, drawing **4 possible colors** (Python random seed 20261018). The set of theoretically possible name/phrase/color questions has size **8 x 3 x 4 = 96**. Reconstructing its 400-case schedule produces just **95 unique triplets** and **305 repeated evaluations**. A frozen model answering the same input multiple times is not an independent new task, so the effective coverage is 95 distinct cases at most, not 400 independent trials. The 400-case statistics describe this particular repeated sampling distribution.

The historical JSON retains **24 example rows**, aggregate accuracies, and subject-versus-unrelated discordances; the remaining raw per-case predictions were not saved, so we cannot recompute a correctly grouped interval for that original run. The original report is immutable in the repository. New benchmark runs record all per-case predictions and their unique-case counts.

A `--design balanced` schedule now covers **all 96 possible cases exactly once**, in a reproducible seeded shuffle. Even that is *not independent confirmation*: those eight names and three phrasings have been examined in previous experiments.

## Gate interpretation

- **W1a: Answer-site correct-color steering versus no-memory** — supported as a straightforward output intervention (100% versus 31.25% four-choice). But unrestricted exact-token accuracy is 64%, not 100%.
- **W1b: Subject-site directed color pulse versus random or wrong-color pulse** — favorable descriptive contrast: 42.25% versus 30.50% and 22.50%. This suggests a content-dependent intervention, *not* a uniquely useful name address.
- **W1c: Subject site versus same pulse on unrelated earlier token** — **not supported**: 42.25% versus 45.25%, with the subject *worse* at this layer/gain.
- **W1d: Attribution to particular attention heads** — **not tested**. A downstream effect does not show which attention heads routed it.

Gain 2 injects a vector of **twice the local hidden-state norm**, which is large rather than a linearized small pulse. This experiment uses **logit-lens vectors**, not the Jacobian lens used in Naula N2. It supplies both entity address and target color by an exact dictionary outside Qwen. Nothing here demonstrates native addressing, learning from prose, a discovered K-space, or biological dendritic routing.

**Next research question:** do any *causally specific* early token/attention-head mechanisms support transporting an injected remembered property, across **unseen names and prompts**, after controls for same-direction, same-gain perturbation at unrelated positions? Freeze such a protocol before running, and use distinct held-out cases rather than repeated queries.

The result worth preserving is that the easy direct-answer intervention works, while **the particular subject-site routing hypothesis remains unconfirmed**.
